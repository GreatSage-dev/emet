Why normal AI wallets get drained

If an AI agent holds a normal wallet key and reads the open web, one bad webpage or shady payment link can talk it into sending everything away.

Without EMET

1. One brain does everything
The same AI that reads untrusted emails and webpages also decides how much money to send.
2. Master key in memory
The agent signs with a full wallet key that can empty the entire balance in one transaction.
3. Blind cross-chain sends
Money leaves immediately. If the swap fails on the other chain, your funds are stuck.

With EMET on NEAR

1. Reader vs. rule checker
The reader extracts the payment details, then all webpage words are stripped before the rule check runs.
2. Limited key + contract rules
The agent only holds a FunctionCall key. The NEAR contract checks token lists, return rates, and spend caps.
3. Escrow until delivery
Funds stay held until v1.signer-prod.testnet verifies the foreign block, or return 100% on failure.
