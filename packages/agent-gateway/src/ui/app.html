    Don't trust this page. Ask the chain.

    Each check runs in your browser against public NEAR and BNB Chain nodes. Our server takes no part.

    1. The live contract is the code in the repo

      Your browser downloads the published contract file, hashes it, and compares it with the hash NEAR reports for the account.

      Not run

    2. The agent's key can ask, not take

      The agent signs with a key that may call one method, on one contract, with a capped gas allowance.

      Not run

    3. The rules live on-chain

      The minimum-return rule and the token list are read from contract storage, not from this website.

      Not run

    4. The cross-chain payment adds up

      Your browser rebuilds the payment request from the NEAR transaction and hashes it with SHA-256. It must equal what the contract stored.

      Not run

    5. NEAR's signer network signed that same hash

      The reply came from v1.signer-prod.testnet itself, inside the same transaction.

      Not run

    6. BNB Chain agrees the payment happened

      Your browser asks a public BNB testnet node for the original transaction and compares the block.

      Not run

    Put your own agent behind EMET.

    Four steps, from a test run on your laptop to your own vault on NEAR testnet.

    1

    Run the tests

    Twelve tests run against the compiled contract file. You don't need Rust for this.

    git clone https://github.com/GreatSage-dev/emet
cd emet
npm test
    2

    Ask EMET before your agent pays

    Send whatever your agent read. The answer is ALLOW, WARN (you decide) or BLOCK, with the reasons.

    
          
    
        
    
      
    
      
    
        3
        
    
          
    Deploy your own vault
    
          
    Creates a fresh testnet account, deploys the contract, fires the six attacks and saves every receipt to testnet-deployment.json.
    
          
    rustup target add wasm32-unknown-unknown
npm run build:wasm
npm run deploy:testnet
    
          
    
        
    
      
    
      
    
        4
        
    
          
    Give your agent a key that can only ask
    
          
    With near-cli-rs. The key can call initiate_intent on your vault and nothing else. Changing rules needs your own key.
    
          
    near account add-key YOUR-VAULT.testnet \
  grant-function-call-access \
  --allowance '1.5 NEAR' \
  --contract-account-id YOUR-VAULT.testnet \
  --function-names initiate_intent \
  use-manually-provided-public-key ed25519:AGENT_PUBLIC_KEY \
  network-config testnet sign-with-keychain send
